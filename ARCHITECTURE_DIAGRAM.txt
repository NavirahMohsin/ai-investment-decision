┌─────────────────────────────────────────────────────────────────────────────┐
│                      SERVICES LAYER (Business Logic)                        │
│                                                                             │
│  NewsAnalyzer (news_analysis.py)                                            │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │                                                                       │ │
│  │  Input: headline, summary, content                                   │ │
│  │         ↓                                                            │ │
│  │  1. Sentiment Analysis ────────────────────────────────────────────┐ │ │
│  │     ┌─ Try FinBERT (ProsusAI/finbert) ─────────────────────────┐  │ │ │
│  │     │ • Load model from cache or HuggingFace                   │  │ │ │
│  │     │ • Tokenize text (max 512 tokens)                         │  │ │ │
│  │     │ • Forward pass through BERT (12 layers)                  │  │ │ │
│  │     │ • Output: [positive, negative, neutral] logits           │  │ │ │
│  │     │ • Softmax → probabilities                                │  │ │ │
│  │     │ • Return: score (-1 to 1), label, confidence             │  │ │ │
│  │     └─ Fallback to TextBlob if FinBERT fails ─────────────────┘  │ │ │
│  │       • Fast polarity calculation                                 │ │ │
│  │       • Lower accuracy but reliable                              │ │ │
│  │                                                                   │ │ │
│  │  2. Event Classification ──────────────────────────────────────┐ │ │
│  │     • Match keywords in headline + summary                     │ │ │
│  │     • 8 categories:                                            │ │ │
│  │       earnings, acquisition, litigation, regulatory,          │ │ │
│  │       management, partnership, product, other                 │ │ │
│  │     • Weighted scoring per category                           │ │ │
│  │     • Return: category, confidence, reasoning                │ │ │
│  │                                                                │ │ │
│  │  3. Market Impact Scoring ─────────────────────────────────────┐ │ │
│  │     • Base: Category weight (0.95 for earnings)               │ │ │
│  │     • Adjust: Sentiment strength (±0.1)                       │ │ │
│  │     • Adjust: Urgency keywords (+0.15)                        │ │ │
│  │     • Adjust: Classification confidence (×0.7-1.0)            │ │ │
│  │     • Return: score (0-1)                                     │ │ │
│  │                                                                │ │ │
│  │  Output: NewsAnalysis object                                  │ │ │
│  │  {                                                             │ │ │
│  │    headline, summary,                                          │ │ │
│  │    sentiment: {score, label, confidence, model},              │ │ │
│  │    event_category: {category, confidence, reasoning},         │ │ │
│  │    market_impact_score,                                        │ │ │
│  │    analysis_version                                            │ │ │
│  │  }                                                             │ │ │
│  │                                                                │ │ │
│  └────────────────────────────────────────────────────────────┘  │ │
│                                                                       │

================================================================================
                            DATA FLOW EXAMPLE
================================================================================

1. NEWS INGESTION
   └─> NewsArticle created with headline, summary, content, source URL

2. NLP PROCESSING
   NewsAnalyzer.analyze()
   ├─ FinBERT: "Apple beats earnings" → {score: 0.92, label: "positive"}
   ├─ Event: Keywords → "earnings" category (0.99 confidence)
   └─ Impact: 0.95 (earnings have high impact)

3. DATABASE STORAGE
   UPDATE news_article SET
     sentiment_score = 0.92,
     sentiment_confidence = 0.94,
     sentiment_model = 'finbert',
     event_category = 'earnings',
     event_confidence = 0.99,
     market_impact_score = 0.95,
     analysis_version = 'v1.0',
     analyzed_at = NOW()
   WHERE id = 123;

4. API AGGREGATION
   GET /api/v1/news/company/1/sentiment?days=30
   ├─ Query: NewsArticle WHERE company_id=1 AND analyzed_at > 30 days ago
   ├─ Aggregate: AVG(sentiment_score), COUNT by category
   └─ Return: {avg_sentiment: 0.34, positive: 12, negative: 5, neutral: 7}

5. FRONTEND FETCH & DISPLAY
   CompanyNewsPanel
   ├─ Fetch: GET /api/v1/news/company/1/articles?limit=20
   ├─ Receive: [Article, Article, Article, ...]
   ├─ Render: SentimentBadge, EventCategoryBadge, NewsArticleCard
   └─ Display: On stock detail page with sentiment indicators
